# rendergrid

Render host/grid network string helpers for config audits.

**Site:** https://theworker02.github.io/rendergrid/

## Install / run

```bash
git clone https://github.com/theworker02/rendergrid.git
cd rendergrid
node src/cli.js
node --test
```
